# Screenshots Directory

Place your application screenshots here with the following filenames:

1. `feedback_inbox.png` - Feedback Inbox screenshot
2. `themes.png` - Themes & Clusters screenshot
3. `impact_scoring.png` - Impact Scoring dashboard screenshot
4. `roadmap.png` - AI Roadmap Generator screenshot
5. `features.png` - Feature Recommendations screenshot
6. `reports.png` - Quarterly Reports screenshot
7. `competitors.png` - Competitor Radar screenshot

The PDF generator will automatically include these images when generating the report.
